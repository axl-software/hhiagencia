# HHA Business Model V1.1

## Revenue model
Primary model: **implementation fee + recurring monthly revenue**.

## Current priority
Generate initial capital through web development.

## Sales approach
Founder-led. Herbert primarily handles outreach, meetings, proposals and closing.

## Offer strategy
Web packages:
- Web Start
- Web Business
- Web Pro

Web Business should be positioned as the strongest value-to-price option.

## Pricing rule
Do not display public package prices until costs, margins and delivery scope are approved.

Use:
- **Solicita cotización**
- **Agenda una reunión**

## First milestone
Close the first web-development client with implementation fee, recurring monthly component, clear scope and repeatable delivery process.
