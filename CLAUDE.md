# HHA Project Instructions

This repository belongs to **HHA Digital Solutions**.

## Source of truth
Before making strategic, branding, UX/UI, service, pricing, marketing, or architectural decisions, read the relevant files inside `/docs`.

Priority:
1. `docs/HHA_MASTER_CONTEXT.md`
2. `docs/HHA_BRAND_FOUNDATION.md`
3. `docs/HHA_DESIGN_SYSTEM.md`
4. `docs/HHA_SERVICES.md`
5. `docs/HHA_BUSINESS_MODEL.md`
6. `docs/HHA_TECH_STACK.md`
7. `docs/HHA_CHANGELOG.md`

If current code conflicts with an approved rule in these documents, the approved memory takes precedence unless the founders explicitly say otherwise.

## Core operating rule
**Build first what is necessary to sell. Automate only what already works.**

## Truth over agreement
Do not agree with the founders merely to be helpful. If a proposal is technically incorrect, commercially unrealistic, strategically inconsistent, unsupported by evidence, or contradictory with approved decisions, state the issue clearly and propose the correction.

## Memory protocol
Do not treat brainstorming as an approved decision.

- IDEA: exploratory only; do not persist.
- TEST: may be implemented temporarily; do not change permanent rules.
- APPROVED: update the relevant memory document.
- SUPERSEDED: replace the old rule and record the change in `docs/HHA_CHANGELOG.md`.

When a founder says “Guarda esto en memoria”, “Actualiza la memoria”, “Esto queda aprobado”, “Esto reemplaza lo anterior” or equivalent:
1. identify the relevant document,
2. update the existing section instead of duplicating information,
3. preserve unrelated valid information,
4. log material changes in `HHA_CHANGELOG.md`.

If a new instruction conflicts with an approved rule and replacement intent is unclear, ask one short clarification.

## Brand protection
Do not:
- invent new brand colors,
- replace approved fonts,
- redesign the logo without approval,
- invent services, pricing, clients, case studies, metrics or testimonials,
- present experiments as confirmed offers.

## Website priority
1. commercial website that generates leads,
2. internal systems,
3. client portal.
